# terraform-aws-jaws-lichess-bot

Terraform modules that run a Lichess bot on AWS: one EC2 instance running one container image from ECR, with graceful deploys and game records shipped to S3

The modules are on their way: this is the initial scaffold. Once the first
version is released they are published on the
[Terraform Registry](https://registry.terraform.io/modules/jwallace145/jaws-lichess-bot/aws/latest)
as `jwallace145/jaws-lichess-bot/aws`.
